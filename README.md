# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple Bash-based application that calculates simple interest based on user-provided input.

## Features
- Accepts principal amount from the user.
- Accepts annual rate of interest.
- Accepts time period in years.
- Calculates simple interest.
- Displays the total amount.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Technologies Used
- Bash Scripting
- Linux Command Line

## Usage
Run the `simple-interest.sh` script in a Bash terminal and enter the required values when prompted.

## Project Purpose
This project demonstrates basic Bash scripting, user input, arithmetic operations, and command-line execution.
